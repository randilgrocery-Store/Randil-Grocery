# Randil Grocery POS — Login Credentials

Keep this file in a safe place. These are the standard logins that exist in
the database on every installation of the **Randil Grocery POS** desktop
system (they are created automatically when the program first opens its
database).

## Desktop POS (Windows) — standard accounts

| Username | Password | Role                  |
| -------- | -------- | --------------------- |
| `admin`  | `admin123` | Administrator (owner) |
| `cashier`| `1234`   | Cashier               |

- Login screen: enter the username, type the password and press **Login**.
  The Administrator can do everything (stock, reports, users, settings).
  The Cashier account is for billing and day-to-day counter work.
- You can change a password any time on the **Settings → Profile / Users**
  screen. Forgot a password? Ask Jerusha Tech Solutions
  (070 3027 611 — jerushasharon1999@gmail.com) to reset it.

## Phone app (Randil Grocery POS — Android)

The phone app has **no username or password** — there is nothing to log in
with. It opens straight to the shop's live dashboard once it has been set up:

- Desktop: **Settings → Cloud** — URL and anon key.
- Phone: the app's **Setup** screen — same URL and anon key + shop name.

These two codes (Supabase project URL + anon key) are given during setup by
Jerusha Tech Solutions; they are the same for both the desktop cloud sharing
and the phone app.
